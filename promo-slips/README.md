# promo-slips

Screenshots of the FanDuel slips behind the promoted bets, named `<week>-<slot>.png` or `.jpg` to match the row on the
'PROMO - Promoted Bets' tab (e.g. `6-1.jpg` = Week 6, slot 1). The weekly rebuild drops the matching screenshot into the
phone frame on the social posters (betsweep.co/promo/). No screenshot = a BetSweep-styled slip is drawn instead.
