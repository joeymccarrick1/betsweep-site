API

Everything on this site is built from JSON the site also serves. Read it from anything - a spreadsheet, a bot, your own page. No key, no sign-up; same-origin and cross-origin GETs both work. Numbers are the model's, prices are FanDuel's at build time unless the file says otherwise. Please cache for a few minutes and credit betsweep.co. Not betting advice.

Keys

A slip key is Player|Market|Line with the line rounded to an integer the way JavaScript's Math.round does it (Josh Allen|Passing Yds|250); the same key appears in price moves, closing lines, box scores and saved slips, so the files join on it.
