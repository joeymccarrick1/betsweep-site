# posts

Drop the pictures you post on X / Instagram in here (jpg, png, webp). The home page shows the newest six,
sorted by file name, newest first — so name them with the date in front, e.g. `2026-10-16-week7-slate.png`.
Nothing else to do: the next site rebuild (Thu / Sat / Sun / Tue) picks them up, and this folder is never cleared by the rebuild.
